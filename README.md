# 今天吃什么？

白头的个人美食日记。沿着时间轴，记录吃过的店、食物、照片与当时的感受。

## 在线浏览

**[打开美食日记](https://baitou-13.github.io/foodmap/)**

## 功能

- 按年份与月份浏览美食记录
- 从时间轴进入每篇帖子的详情页
- 展示帖子正文、日期、作者、互动数据及全部配图
- 保留原帖链接，方便查看原始内容与评论
- 响应式布局，支持桌面和手机浏览

## 项目结构

```text
.
├── index.html          # 时间轴首页
├── post.html           # 帖子详情页模板
├── app.js              # 首页数据渲染与交互
├── post.js             # 详情页数据渲染
├── posts.js            # 美食帖子数据
├── styles.css          # 全站样式
└── assets/
    ├── brand/          # 网站标志
    └── food/           # 帖子图片
```

## 本地运行

项目没有第三方依赖。进入项目目录后启动任意静态文件服务器，例如：

```bash
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

> 详情页通过查询参数读取帖子，例如 `post.html?id=2025-5-14.2`。建议通过静态服务器预览，不要直接双击 HTML 文件。

## 数据说明

每篇记录由 `posts.js` 中的一条数据描述，图片放在对应日期目录中：

```text
assets/food/<帖子标识>/image-01.jpg
```

当前本地数据包含帖子正文、图片、发布时间和互动数量，不包含评论正文。详情页会引导访客前往原帖查看评论。

## 部署

网站使用 GitHub Pages 发布，发布源为 `main` 分支根目录。推送更新后，GitHub Pages 会自动重新构建。

## 技术特点

- 原生 HTML、CSS 与 JavaScript
- 无框架、无构建依赖
- 纯静态部署
- 数据与页面逻辑分离
